Betterland: A Web-First Scientific Poster for Quarto

An MVP extension for semantic, responsive, and print-feasible academic posters

Firmin C., Another Contributor

1 RPTU Kaiserslautern-Landau

2 Example Research Lab

A semantic, web-first poster can preserve the visual strengths of a “better poster” while improving screen readability and structural flexibility.

The MVP already supports the core content types needed for a usable scientific poster in Quarto.

This makes the extension a strong baseline for future work on richer poster components, accessibility, and interactive HTML output.

Introduction

Scientific posters are usually designed for print and later distributed as PDFs.
This often makes them difficult to read on screens, difficult to search, and less adaptable than HTML-based documents.

This prototype explores a web-first poster model for Quarto, combining: - semantic structure - responsive presentation - print-feasible export - support for common scholarly poster content

Contributions

This MVP focuses on the most important poster requirements:

  • semantic header, key-message, support, detail, and resources regions
  • responsive screen layout for web viewing
  • print-feasible A0/A1 output
  • support for text, lists, images, tables, references, and resources
  • an extensible baseline for future scientific-poster components

Methods

The implementation is based on three layers:

  1. Lua transformation to classify and reorganize content into semantic poster regions
  2. HTML template to provide a clean web-first container and poster variables
  3. CSS / print CSS to create responsive screen layout and print behavior

This keeps the authoring experience close to standard Quarto while introducing poster-specific structure.

Implementation

The poster extension currently supports:

  • metadata extraction from YAML
  • automatic header generation
  • explicit .key-message block extraction
  • explicit .resources block extraction
  • default support/detail splitting around the key message
  • semantic region wrappers for accessibility and maintainability

Evaluation

The MVP was evaluated against the following questions:

  • Can the poster be meaningfully read in a browser without behaving like a static PDF?
  • Can the same source be printed into a poster-sized output?
  • Can common scientific poster content types be displayed without custom author-side hacks?
  • Does the structure remain extensible enough for future work?

Detail Example

The extension is intended to support richer scientific content over time.
For example, compact technical detail can already be included:

def classify_blocks(blocks):
    support = []
    detail = []
    seen_key = False
    for block in blocks:
        if block.get("is_key"):
            seen_key = True
        elif seen_key:
            detail.append(block)
        else:
            support.append(block)
    return support, detail

An example mathematical expression may also appear in technical posters.

For instance, the F1-score can be written as:

\[ F_1 = 2 \cdot \frac{\mathrm{Precision} \cdot \mathrm{Recall}}{\mathrm{Precision} + \mathrm{Recall}} \]

Discussion

The MVP is already sufficient to demonstrate the project goals, but several limitations remain.

Current limitations include:

  • browser-specific print inconsistencies
  • only partial optimization for code and equations
  • limited component-level presets for figures, callouts, and tables
  • incomplete control over PDF logical reading order

Future Work

The most important next steps are:

  • improved figure and table styling by region
  • callout and note components
  • stronger support for equations and code
  • richer key-region visual elements
  • improved PDF reading-order robustness
  • optional interactive HTML poster features
